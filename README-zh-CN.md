# Just Items Viewer

[English](README.md) | **简体中文**

**浏览物品、查询配方与用途，并在书签中规划制作需求。**

Just Items Viewer（**JIV**）是一款面向 **Minecraft 26.1.2 / NeoForge** 的物品与配方查看模组，源自 Just Enough Items（JEI）。打开背包或合成界面，即可浏览物品、搜索材料、查看合成方式和用途。

| Minecraft | 模组加载器 | 当前版本 |
| --- | --- | --- |
| 26.1.2 | NeoForge | 0.0.1-alpha-3 |

更新说明：[0.0.1-alpha-3](CHANGELOG.md)。此版本已发布到 [Maven Central](https://central.sonatype.com/artifact/io.github.eakerzt/jiv-26.1.2-neoforge/0.0.1-alpha-3)。

## 功能

- **物品浏览与搜索**：在侧栏浏览物品，按名称、模组、标签等条件筛选。
- **配方与用途查询**：查看物品如何制作，以及哪些配方需要该物品。
- **物品与配方书签**：收藏物品、流体或指定配方产物，管理书签空间与书签组，通过拖拽预览排序、选择替代材料。
- **配方链与制作树**：根据已收藏的配方计算材料需求，查看中间制作步骤和合成媒介／配方分类角标。
- **查询历史**：快速回到最近查看过的物品。
- **配方填充**：在支持的容器中，将背包材料填入配方槽位。
- **配方显示 API**：支持配方界面扩展、原生侧面板、流体数量，以及不消耗／概率槽位标记。
- **内置设置**：配置物品列表、搜索、书签和提示信息。
- **作弊模式**：在拥有相应权限时直接获取物品。

## 安装

1. 安装 **Minecraft 26.1.2** 和 **NeoForge 26.1.2.99 或兼容 Minecraft 26.1.2 的更新版本**。
2. 将 `jiv-26.1.2-neoforge-0.0.1-alpha-3.jar` 放入游戏实例的 `mods` 文件夹。
3. 启动游戏，打开背包。

设置界面和搜索功能均已内置，**无需另行安装 MezzConfig、MezzConfigGUI 或搜索库**。

只在客户端安装即可浏览物品和查看配方。多人游戏中，需要服务端支持的功能（例如配方填充）还需在服务端安装 JIV；作弊模式遵循服务端权限设置。

## 快速上手

以下为界面打开时的默认快捷键。查询配方、用途或收藏前，先将鼠标放在目标物品上。

| 操作 | 默认快捷键 |
| --- | --- |
| 查看合成方式 | `R` |
| 查看用途 | `U` |
| 收藏／取消收藏物品 | `A` |
| 显示／隐藏 JIV 覆盖界面 | `Ctrl + O` |
| 聚焦搜索框 | `Ctrl + F` |

可以在 **选项 → 控制 → 按键绑定** 中修改快捷键。下文书签操作中的 `Ctrl` 在 macOS 上也指实体 Control 键；其他可配置快捷键可能使用 Command。

在搜索框中输入物品名称，或使用前缀缩小搜索范围：

| 示例 | 搜索范围 |
| --- | --- |
| `@minecraft` | 模组名称或模组 ID |
| `#logs` | 物品标签 |
| `$fuel` | 提示文本 |

搜索采用当前游戏语言，也可在设置中启用物品 ID、创造模式标签页和颜色搜索。

## 书签操作

使用快捷键前，先将鼠标放在目标槽位上。下文 `A` 代表配置的“收藏”快捷键，默认值为 A。书签面板外的收藏操作匹配当前书签空间内的全部未分组书签，跨书签页查找；书签组内的记录不参与匹配。同一配方不区分单产物、全产物或已删除材料的状态，已存在时取消全部匹配记录，否则新增。独立物品／流体同样切换收藏，配方中的材料不算独立收藏。

| 位置／操作 | 默认操作方式 |
| --- | --- |
| 书签面板内：移除指向的物品／流体，包括配方原料与产物 | `A`（无修饰键） |
| 配方页面的产物：切换该配方收藏，新收藏只记录当前产物 | `A` |
| 其他位置：切换独立物品／流体收藏 | `A` |
| 配方槽位或配方书签：收藏／取消收藏配方，只记录当前产物；在原料上操作则记录第一个产物 | `Ctrl + A` |
| 配方槽位或配方书签：收藏／取消收藏配方，记录全部产物 | `Ctrl + Shift + A` |
| 配方界面的收藏按钮 | 收藏／取消收藏完整配方 |
| 配方书签产物：查看已收藏的配方 | 左键／`R` |
| 任意材料：查看用途 | 右键／`U` |
| 配方书签产物：移动整条配方，可跨书签组 | `Ctrl + 左键拖拽` |
| 配方书签原料：调整本配方内合并原料格的顺序 | `Ctrl + 左键拖拽` 到同一配方的另一原料上 |
| 独立物品书签：调整位置，可跨书签组 | `Ctrl + 左键拖拽` |
| 配方书签：折叠／展开原料 | `Alt + 左键` |
| 产物：调整配方批次；独立物品：调整数量 | `Ctrl + 滚轮`；加 `Alt` 按堆叠上限调整 |
| 可替换原料：选择上一个／下一个候选材料 | `Ctrl + 滚轮` |
| 材料槽位：复制当前显示的名称 | `Ctrl + C` |
| 配方书签：填充一次／尽量填充 | `Alt + 右键`／`Ctrl + 右键`（可配置填充键位在 macOS 上可能使用 Command） |
| 显示／隐藏书签 | `B` |

搜索框或文本输入框聚焦时，`Ctrl + A` 保留文本全选行为。在普通背包槽位或物品列表上使用配方收藏快捷键，不会自动选择某条配方。

单产物配方书签的**显示和计算**都只考虑记录的产物。未记录的副产物不会供给关联配方，也不会计入剩余产物；需要这些产物参与时，使用 `Ctrl + Shift + A`。在书签面板中移除原料后，材料需求计算和填充都排除该原料；合并原料格代表的全部槽位一起移除，可替换原料格删除整个需求。最后一个产物移除时，整条配方及剩余原料一起取消收藏。查看配方仍展示原始完整配方。

将配方拖到最后书签组下方的空白处，或其末行底边，可放到书签组之后的默认组。默认组内容可以位于书签组之前、之间或之后。在书签组线条上 `Ctrl + 左键拖拽`，会将整组作为一个整体移动，保留组内顺序及设置；松手确认，取消恢复。

拖拽排序时，被拖动原料变为灰色占位符，实时预览插入位置，其他原料随之移位。拖动产物时，整条配方的可见物品一起跟随鼠标，并保留整块占位。松手保留最后一次有效预览，即使鼠标已移出有效区域；取消拖拽才恢复原顺序。原料排序固定视口和其他配方的位置，预览确认后才保存。

同一配方内的相同原料会合并。移动合并原料时，其所有原始槽位一起移动，不改变数量或候选选择；原料不能移入其他配方。原料顺序、产物选择、候选材料、数量、分组和布局都会保存。旧配方记录加载后保留全部产物。

### 模式、悬停与替代材料

顶栏左侧的模式图标显示并切换**默认分组**的布局：**物品模式**只显示配方产物，**配方模式**按行显示产物与原料。其他书签组保留各自布局。

导航和模式按钮采用相同尺寸，窄侧栏中的数字会缩放以适应空间。模式切换只改变显示方式，不改变 `A`、`Ctrl + A` 或 `Ctrl + Shift + A` 的收藏规则。

在配方模式下，悬停任一材料会为所属配方的可见槽位添加背景：产物为蓝色、原料为绿色、剩余产物为紫色。当前槽位的普通悬停高亮叠加在背景上，无需按住 Shift。

可替换原料沿用配方界面标识：识别到标签时显示 `#`，普通候选列表显示 `≡`。悬停可查看候选列表，当前选项带绿色边框。按住 `Shift` 聚焦提示后，可滚动列表，并用左／右键或 `R`／`U` 查询候选材料的配方和用途。不消耗原料显示与配方槽位相同的绿色 `∞`。在关联计算的书签组中，按住 `Shift` 还可查看汇总需求／产物数量。

### 书签空间、书签页与书签组

上方左右按钮切换书签空间，滚轮翻阅空间内的书签页，用线连接的收藏称为书签组。物品槽位左侧的 7 像素区域用于操作书签组。顶栏显示“当前书签空间／总空间数”；空间有多页时，还会显示“当前书签页／总页数”。

| 位置／操作 | 行为 |
| --- | --- |
| 顶栏左右箭头 | 切换书签空间；最后一个非空空间继续向右会创建空空间 |
| 书签内容区域 | 滚轮翻阅当前空间的书签页／滚动行 |
| 拖动书签靠近分页边缘 | 在排序时翻页／滚动当前组 |
| 模式图标 | 切换默认分组的物品／配方布局 |
| 书签组线：左键单击 | 切换该书签组的物品／配方布局 |
| 书签组线或中央数字：右键 | 开关配方链计算 |
| 书签组线或中央数字：`Alt + 左键` | 折叠／展开分组 |
| 左侧分组区域：左键跨行拖拽 | 创建书签组，或将选中行加入起始书签组 |
| 左侧分组区域：右键跨行拖拽 | 将选中行移出书签组 |
| 书签组线：`Ctrl + 左键拖拽` | 移动整个书签组 |
| 书签组的线：无修饰键的 `A` | 删除该书签组及其书签 |
| 顶栏中央标题／计数：无修饰键的 `A` | 删除当前书签空间的全部内容，包括书签组；切换到相邻空间，至少保留一个空空间 |
| 书签组线或中央数字：查看合成方式快捷键（默认 `R`） | 打开制作树，随自定义配方键位变化 |
| 书签组线或中央数字：`V`／`Shift + V` | 从支持的容器取出所需材料／只取缺少材料 |

### 制作树与显示设置

制作树中的配方节点（包括中间配方和折叠节点）显示与书签栏一致的合成媒介／配方分类角标；原材料叶节点不显示角标。

在制作树中，左键拖拽平移，滚轮缩放，左键点击节点折叠／展开分支，右键查看配方，`Ctrl + C` 复制节点材料名称。顶部按钮可切换背包快照（`I`）、适应窗口（`F`）、折叠分支和显示／隐藏统计（`S`）。在统计面板上滚动可浏览材料列表，`Esc` 返回此前界面。

书签和查询历史默认开启，历史默认显示在右侧。可在配置界面修改显示状态及历史所在侧。设置中还可禁用拖拽排序、调整拖拽延迟和新书签插入位置。

普通物品书签初始没有保存数量，因此不显示数量角标；配方快捷键初始记录一个批次。消耗原料和已记录产物的数量随配方批次增加，不消耗工具不随批次数量累乘。

## 设置

点击物品列表旁的**设置按钮**，或从 NeoForge 模组列表打开 JIV 配置界面。

可以调整列表布局、物品排序、搜索选项、书签显示和提示行为。配置文件位于游戏实例的 `config/jiv/` 文件夹。

## 兼容性

JIV 当前支持 **Minecraft 26.1.2 / NeoForge**。

其他模组通过标准配方系统提供的配方可在 JIV 中查看。依赖专用接口或 JEI 插件的自定义配方显示需要接入 JIV；现有 JEI 插件不能直接加载。
